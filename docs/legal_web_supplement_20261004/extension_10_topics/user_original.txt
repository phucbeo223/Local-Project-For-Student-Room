### 2. NHỮNG PHẦN DỮ LIỆU ĐỊA PHƯƠNG CẦN BỔ SUNG NGAY

Để câu trả lời mang đậm tính thực tế hỗ trợ **sinh viên Đại học Cần Thơ**, bạn nên thêm 2 file dữ liệu địa phương này vào thư mục `data/`:

#### A. File `data/cantho_contacts.md` (Danh bạ & Hotline hỗ trợ khẩn cấp)
* **Tổng công ty Điện lực miền Nam (EVNSPC):** Hotline `1900 1006` hoặc `1900 9000` (tiếp nhận phản ánh giá điện nhà trọ).
* **Công ty CP Cấp thoát nước Cần Thơ (Cantho Water):** `(0292) 3830 248`, tra cứu tại `canthowater.vn`.
* **Công an các phường trọng điểm quanh các khu ĐH Cần Thơ:**
  * Phường Xuân Khánh (quận Ninh Kiều - cổng 3/2 Khu II ĐHCT): `(0292) 3830 081`
  * Phường An Khánh (quận Ninh Kiều - gần cổng phụ, hồ Búng Xáng, KTX): `(0292) 3897 456`
  * Phường Hưng Lợi (quận Ninh Kiều - khu vực đường 30/4, Tầm Vu): `(0292) 3838 527`
  * Phường An Bình (quận Ninh Kiều - gần cầu Cái Răng, chợ Da Liễu): `(0292) 3846 113`
* **Cảnh sát PCCC & CNCH Công an TP. Cần Thơ:** `114`

#### B. File `data/legal_templates.md` (Các biểu mẫu hướng dẫn thực tế)
* **Mẫu Tờ khai thay đổi thông tin cư trú CT01** (hướng dẫn cách ghi mục "Ý kiến của chủ hộ/chủ chỗ ở hợp pháp").
* **Mẫu Hợp đồng thuê nhà trọ chuẩn** (có sẵn các điều khoản bảo vệ sinh viên về tiền cọc, số điện thoại chủ nhà, đơn giá điện nước minh bạch).
* **Mẫu Đơn tố giác tội phạm lừa đảo chiếm đoạt tiền cọc trọ** gửi cơ quan Công an.

### 3. CẤU TRÚC CHUẨN ĐỂ FORMAT FILE TRONG `data/` CHO CHATBOT (RAG)

Khi bổ sung file vào thư mục `data/`, hãy cấu trúc theo định dạng Markdown có **Metadata đầu mục** để mô hình Retrieval (Embedding/BM25) tìm kiếm chính xác nhất:

```markdown
# CHỦ ĐỀ: [Tên chủ đề]
Tags: [housing_contract | electricity | water_cantho | fire_safety | ...]
Văn bản áp dụng: [Tên Luật / Nghị định / Thông tư cụ thể]
Thời điểm áp dụng: [Hiện hành - năm 2024 / 2025 / 2026]

## 1. TÓM TẮT QUY ĐỊNH
... (Nội dung súc tích, gạch đầu dòng) ...

## 2. ĐIỀU KHOẢN TRÍCH DẪN NGUYÊN VĂN
... (Trích dẫn nguyên văn Điều... Khoản...) ...

## 3. CÁC TÌNH HUỐNG THỰC TẾ & CÂU HỎI THƯỜNG GẶP CỦA SINH VIÊN
Q: ...
A: ...
```

👉 **Việc bạn cần làm ngay:** Kiểm tra danh sách file trong thư mục `data/` của bạn, đối chiếu với 10 chủ đề trên. Nếu thiếu file nào (đặc biệt là **PCCC theo Nghị định 50/2024**, **Luật Nhà ở & Kinh doanh BĐS 2023 mới**, hoặc **Danh bạ Công an phường tại Cần Thơ**), bạn hãy tạo thêm file tương ứng. Nếu bạn cần tôi soạn sẵn nội dung đầy đủ của file nào, bạn chỉ cần gọi tên file đó!
